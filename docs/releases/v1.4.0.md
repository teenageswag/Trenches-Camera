# trenches 1.4.0

- **Dither** для камеры, фото и видео. Есть Bayer 2×2, 4×4 и 8×8, Blue noise, White noise и шесть режимов диффузии ошибки. Можно настроить размер пикселя, порог, интенсивность, число уровней и смешивание. Палитры включают чёрно-белую, настраиваемый дуотон, цвета кадра и готовые варианты.
- **Классический ASCII** теперь поддерживает 11 наборов символов, включая Braille, Matrix, Silk и Pencil. Сохранённые пресеты используют прежний рисунок своих наборов.

iOS 18 и новее. Скачайте `trenches-1.4.0.ipa` и подпишите своим Apple ID через [Sideloadly](https://sideloadly.io/). Чтобы сохранить съёмки и пресеты, устанавливайте поверх предыдущей версии с тем же Apple ID и Bundle ID.
