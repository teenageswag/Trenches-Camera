# Lens dirt

`LensDirt.png` is a project asset generated with the built-in imagegen tool.
Prompt: "Grayscale lens dirt mask texture for a GPU camera lens-flare effect. Square black background with scattered tiny gray and white dust specks, soft irregular out-of-focus small circular dust particles, and a few very subtle broad wiping smudges. Flat texture covering whole image, no objects, no glass rim, no lights, no lens flares or vignette, no text. Predominantly black, isolated dust at different scales, low density. A multiplicative/emissive mask, white dust on black."

Loaded as linear RGB. It emits light only where the shared Bloom/flare bright-pass illuminates it.
